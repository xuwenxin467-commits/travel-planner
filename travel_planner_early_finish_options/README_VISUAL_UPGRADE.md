# Travel Planner — Visual Upgrade

本次升级保留现有功能与页面结构，主要改善视觉体验：
- 更精致的旅行主题渐变背景、卡片层次与阴影。
- 表单、选择按钮、行程卡片、天气卡片和 AI 助手统一视觉风格。
- 增加轻量交互反馈、键盘焦点样式和减少动态效果偏好支持。
- 桌面端规划表单在滚动时保持可见；手机端仍采用单列布局。
- Service Worker 缓存版本更新为 v8，帮助浏览器获取新样式。

本次属于界面与体验升级，不代表已接入实时交通、实时营业时间或自动代用户修改行程。AI 助手仍需在 Vercel 配置 OPENAI_API_KEY 后才能正常调用。
