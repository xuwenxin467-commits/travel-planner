# Travel Planner — Smart Console Upgrade

本次升级是在现有项目基础上增加智能控制台，不替换原有路线规划、地图、保存攻略、行程编辑、提醒和 AI 聊天功能。

## 新增内容

1. **智能旅行控制台**：生成行程后显示目的地、旅行天数、预算和天气策略状态。
2. **旅行花费追踪**：可记录餐饮、交通、门票、购物和其他支出；自动计算已花费与预算余额，并按目的地和出发日期保存在当前浏览器本地。不会自动同步到其他设备。
3. **天气感知建议**：读取现有 Open-Meteo 预报，依据降雨概率、最高/最低气温给出室内/户外活动建议。天气预报并非实时保证，且较远日期可能没有预报。
4. **AI 行程调整上下文**：点击天气卡片中的 AI 按钮，会把天气建议、现有行程和已记录支出带入 AI 对话，帮助提出调整方案。AI 不会未经用户确认直接改动路线。
5. **中/韩/英界面**：新增控制台和费用追踪界面随语言切换。

## 部署

- Vercel Root Directory 继续使用 `travel_planner_early_finish_options`（如果仓库中项目仍位于该子目录）。
- 保持 Build Command 为 `npm run build`，Output Directory 为 `www`。
- AI 功能需要在 Vercel 项目环境变量中配置 `OPENAI_API_KEY`，然后重新部署。不要把 API Key 上传到 GitHub。
- 费用记录使用浏览器 localStorage；清除浏览器网站数据会清除这些记录。
- Android 项目需在本地安装依赖后执行 `npm run android:sync`，再通过 Android Studio 构建 APK。仅部署网站不会自动更新已安装的 APK。

## 能力边界

天气建议使用公开天气预报；本版本不包含实时交通、景点实时营业状态或实时票价 API。费用分类预算是用户录入的实际支出加预算输入，不会自动读取银行卡或支付账户。
